Política de Privacidade

Diário de Notas do Professor

Última atualização: 20 de setembro de 2026

1. Sobre o aplicativo

O Diário de Notas do Professor é uma aplicação destinada ao gerenciamento de turmas, alunos, avaliações e notas acadêmicas por professores.

O aplicativo permite cadastrar instituições, cursos, turmas, disciplinas, alunos e avaliações, registrar notas, calcular resultados, gerar relatórios e realizar exportação e restauração de dados.

2. Dados utilizados pelo aplicativo

Para permitir a identificação do usuário e o funcionamento dos recursos relacionados à conta Google, o aplicativo pode acessar o endereço de e-mail da conta Google utilizada para acessar o sistema.

Os dados acadêmicos inseridos pelo professor podem incluir informações como nomes de alunos, turmas, disciplinas, avaliações, notas, médias, observações e informações relacionadas ao diário acadêmico.

3. Como os dados são utilizados

Os dados são utilizados exclusivamente para fornecer as funcionalidades do Diário de Notas do Professor, incluindo:

  • identificação do usuário;
  • armazenamento e recuperação dos dados do diário;
  • gerenciamento de turmas e alunos;
  • registro e cálculo de notas e médias;
  • geração de relatórios;
  • exportação e restauração de backups;
  • envio de relatórios por e-mail quando solicitado pelo usuário.

4. Armazenamento dos dados

Os dados do diário são armazenados utilizando os serviços do Google associados ao funcionamento do aplicativo. O armazenamento é vinculado ao usuário que utiliza o aplicativo, de acordo com a configuração do sistema.

O usuário também pode realizar exportações e backups dos dados para armazenamento próprio.

5. Compartilhamento de dados

O Diário de Notas do Professor não vende, aluga ou comercializa os dados dos usuários ou dos alunos.

Os dados inseridos no aplicativo não são compartilhados com terceiros para fins de publicidade ou marketing.

Quando o usuário solicita o envio de um relatório por e-mail, os dados necessários para a elaboração e envio desse relatório são processados para executar essa solicitação.

6. Dados de usuários do Google

O aplicativo utiliza os serviços de autorização do Google para permitir o acesso do usuário e utiliza o endereço de e-mail da conta Google para identificação.

Os dados obtidos por meio das APIs e serviços do Google são utilizados somente para fornecer as funcionalidades descritas nesta Política de Privacidade.

O aplicativo não utiliza os dados de usuários do Google para publicidade, venda de informações ou qualquer finalidade incompatível com a funcionalidade do aplicativo.

7. Segurança

São utilizados mecanismos de autenticação e os recursos de segurança disponibilizados pelos serviços do Google para proteger o acesso ao aplicativo e aos dados armazenados.

O usuário também deve proteger sua própria conta Google e não compartilhar suas credenciais de acesso com terceiros.

8. Responsabilidade sobre os dados dos alunos

O professor ou usuário que inserir informações de alunos no sistema é responsável por utilizar esses dados de acordo com a legislação aplicável, as normas da instituição de ensino e as obrigações relacionadas à proteção de dados pessoais.

9. Exclusão dos dados

O usuário pode utilizar os recursos disponíveis no aplicativo para exportar ou substituir seus dados. Para solicitações relacionadas à exclusão ou esclarecimento sobre dados armazenados pelo sistema, o usuário pode entrar em contato pelo e-mail abaixo.

10. Alterações nesta Política de Privacidade

Esta Política de Privacidade poderá ser atualizada quando houver alterações nas funcionalidades do aplicativo ou na forma como os dados são tratados. A versão atualizada será publicada nesta página.
